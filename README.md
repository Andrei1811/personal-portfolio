# Personal Portfolio

A modern and responsive personal portfolio website built with **Next.js**, **React**, and **TypeScript**. The website presents my professional experience, technical skills, projects, achievements, and contact information in a clean and interactive format.

---

## Live Demo

https://andrei-raulea.vercel.app/

---

## Features

- Responsive personal portfolio
- Professional experience timeline
- Technical skills overview
- Featured projects section
- Project links and live demos
- Downloadable CV
- Contact information
- Smooth navigation and interactive interface
- Mobile-friendly design

## Getting Started

### Requirements

- Node.js
- pnpm or npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Andrei1811/personal-portfolio.git
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open:

```text
http://localhost:3000
```
